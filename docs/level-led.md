# 蓝灯声音强度指示

2026-11-06，STM32F407VG / MB997B。使用原先空闲的蓝色 LD6 / PD15，以 TIM4_CH4 硬件 PWM 显示当前声音强弱。
PD15 的蓝灯及 TIM4_CH4 复用关系见 [ST UM1472 用户手册](https://www.st.com.cn/resource/en/user_manual/um1472-discovery-kit-with-stm32f407vg-mcu-stmicroelectronics.pdf)。

| LED | 引脚 | 当前用途 |
| --- | --- | --- |
| 绿色 LD4 | PD12 | 每秒翻转的运行心跳 |
| 橙色 LD3 | PD13 | 降噪已校准且开启 |
| 红色 LD5 | PD14 | 校准时常亮；新保护等待安静时闪烁，详见 [校准保护](calibration-guard.md) |
| 蓝色 LD6 | PD15 | 声音越强越亮 |

四个板载用户 LED 现在均有用途。TIM4 只将 CH4 接到 PD15；PD12～14 仍由 GPIO 控制。
TIM2 继续作为 Embassy 时间基准，音频 DMA / USB 中断及优先级不变。PWM 不使用 IRQ 或 DMA。

## 指示规则

在采集任务中观察降噪后的 f32 PCM；旁路时观察原声，并计入当前数字增益。
指示不依赖 Windows 是否打开录音，因此空闲时说话也能使蓝灯变亮；Windows 静音不会让该采集侧指示熄灭。
仅启用 PDM 诊断时观察原始解码 PCM、按 1× 计算；无采集的纯正弦模式不启动此指示。

每 320 samples /20 ms 计算 RMS。增益若在该窗口内变化，按窗口结束时的 Q8 增益显示。
RMS 8 LSB 以下目标亮度为 0，2048 LSB 及以上为满亮，中间按幅度每翻倍占八分之一范围作近似对数映射。
这是一项便于观察的相对音量指示，不是 dB SPL 声压计；阈值可在 `src/level_meter.rs` 调整。

明暗包络在声音变强时每帧靠近目标一半，变弱时每帧衰减差值的十分之一；使语音反应快、停顿时缓慢变暗。
PWM 占空比使用亮度平方映射，改善暗部的视觉过渡。硬件载波 2 kHz，亮度更新约 50 次 /秒。
当当前音量低于底阈值时，蓝灯可能完全熄灭，这是正常表现。

## 验证

用户在烧录后通过安静、说话 / 拍手观察，反馈“明暗变化正常”。
`tools/check.ps1` 通过，23 项 Rust 测试包含新增的单调 / 边界映射、20 ms 窗与增益响应、快亮慢暗及回到全暗检查。
无 feature、仅 PDM 采集、无降噪原声三种诊断模式也通过 release Clippy。
构建验证 PD15 对 TIM4_CH4 的类型化引脚映射，启动日志给出 2 kHz、最大占空比计数 42000。
完整实板录音、音频错误计数及映像信息见 [验证记录](../artifacts/level-led-validation.json)。
30 秒说话 / 拍手录音无全零毫秒，包含 18 个满幅 WAV 样本；此时固件增益削顶计数为零，未定位振幅饱和发生在哪一层。
随后退出调试器的 10 秒录音无削顶、无全零毫秒；RTT 的 DMA / PCM / USB 七项错误计数均为零。
静态 SRAM 29168 bytes（比此前增加 120 bytes），Flash 映像 89680 bytes。
原始 WAV、RTT 和 BIN 保存在本地 `captures/`，未纳入 Git。频率来自固件配置 / 定时器分频计算，未使用示波器测量。
