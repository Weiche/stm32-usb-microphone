# 音频间断通知与实板验收

2026-11-10，STM32F407VG / MB997B，Windows 10，CN1 供电、CN5 USB 音频。源码基于 `2cb6f56` 加本地未提交的间断恢复改动；完整源码哈希、映像哈希及观测数据见 [验证记录](../artifacts/audio-discontinuity-hardware-validation.json)。

## 恢复机制

队列清空与间断序号递增在同一短临界区完成；空队列也通知，避免保留重采样历史。DMA 环形覆盖和 PCM 队列覆盖都会使序号变化，USB 清流也沿用此机制。输出端发现变化后清除水位控制与重采样历史，重新预填 256 samples，等待期间发送静音。旧包读取会校验序号；包内发生间断则将整包清零。

本次新增的 8 个主机测试涵盖上述状态以及连续通路不变、空队列、序号回绕和新音频恢复，总计 35 个 Rust 测试通过。固件仍保持 16 kHz、16-bit、单声道、32-byte USB 包和既有增益 / 降噪参数。

## 三次真实 DMA 覆盖

烧录前已读取完整 1 MiB Flash 备份，核对其有效映像与先前自动降噪实验版一致。本次正常固件保留 `adaptive-noise`；诊断固件额外启用 `audio-gap-test`，两次烧录均启用写入校验。

`audio-gap-test` 仅用于实板验证，隐含 `live-mic`。每次开机在累计 USB 成功包数达到 8000 /16000 /24000 时，各暂停采集任务 10 ms；DMA 和 USB 音频继续运行。10 ms 超过 8 ms DMA 环形容量，实际走 HAL Overrun → 清队列 / 更新序号 → 重置解码与降噪时域历史 → 输出重新预填的路径。日常构建不启用此 feature。

PC 默认播放输出以 -26.2 dBFS 数字峰值播放 1 kHz 测试音，USB 麦克风录制 40 秒。RTT 完整观察到三次注入及三次 DMA 覆盖，序号随之改变；无额外 USB 错误、DMA 硬件错误、PCM 溢出或输出欠载。噪声谱保持就绪。

| 注入约在录音时间 | 录回接近静音的连续区间 | 恢复后 RMS / 间断前 RMS | 恢复后首 150 ms 最大绝对采样值 |
| --- | --- | --- | --- |
| 8 s | 28 ms | 567 /566 LSB | 5858 LSB |
| 16 s | 29 ms | 556 /556 LSB | 9200 LSB |
| 24 s | 29 ms | 559 /560 LSB | 4840 LSB |

接近静音定义为 1 ms 窗 RMS <2 LSB；Windows 处理带来亚 LSB 抖动，不能用精确零采样代替静音时长。上表时间不是严格端到端延迟，恢复 RMS 取静音结束后 150～230 ms。恢复时存在高于稳态测试音的瞬态，虽然未削顶，仍不能宣称无爆音或无感恢复。

## 正常固件复验

诊断后已换回只启用 `adaptive-noise`、不含 `audio-gap-test` 的正常固件，退出调试器后留其运行。

- 120 秒连续录音：1920000 samples，无削顶、无启动 200 ms 后的全零毫秒。
- 20 次录音关闭后重新打开：每次完成 1 秒 /16000 samples，无削顶。
- 退出调试器后的 15 秒独立录音：240000 samples，无削顶、无启动 200 ms 后的全零毫秒；独立阶段未同时读取 RTT。
- 正常固件 RTT 中七项 DMA / PCM / USB 错误计数均为零；`disabled` / `discarded_samples` 包含正常停止流取消待发包。
- 扬声器分段播放 1 /1.5 /2 kHz。录音选定稳态窗口主峰为 999～1000 /1500 /2000 Hz，相应频点 ±10 Hz 内占窗口频谱功率约 99.7%～99.9%；这是实际声学耦合验证，不能当作标定频响。
- 正常映像占用静态 SRAM 29792 bytes、Flash 93424 bytes；栈峰值未测量。

360 秒 Windows USB 轮询完成 256 次查询；烧录复位期间观察到预期重新枚举，正常版完成校准后未观察到设备变化。轮询可能漏掉短暂变化。

录音测试完成后，附加寄存器检查两次无法重新打开 ST-LINK，返回 `USB error: reset not supported by WinUSB`；执行脚本因此在附加检查处非零退出。之后再次完成 3 秒独立录音（48000 samples，无削顶、无启动 200 ms 后全零毫秒），确认麦克风仍在运行。本轮不报告 CFSR/HFSR/DEMCR 读数，也未因此再次复位或重刷开发板。

本轮不包含物理插拔、断电、实体 RESET、睡眠恢复、Windows 11 或 8 小时录音；也未进行主观语音质量与无爆音验收。有限计数和录音不能证明每个线上 USB 包都到达。

原始 WAV、RTT、完整 Flash 备份、两份固件及本轮执行 / 分析脚本位于本地 `captures/discontinuity-live-20261110-0703/`，不纳入 Git。版本化 JSON 保存哈希与观测摘要。
